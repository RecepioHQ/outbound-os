# Buyer Selection

Outbound OS evaluates four evidence-backed dimensions before outreach: strategic fit, commercial-capacity evidence, decision access, and trigger/timing evidence.

Only `VERIFIED` evidence can support a positive execution score. `INFERRED` and `UNKNOWN` remain visible for research but contribute zero to execution eligibility.

Default outcomes:

- `READY`: the total score and required dimension minimums pass.
- `HOLD`: potentially relevant, but evidence or thresholds are insufficient.
- `SKIP`: an explicit disqualifying condition makes outreach inappropriate.

The default public policy is intentionally conservative and configurable. Every result includes inspectable dimension scores and reasons.
